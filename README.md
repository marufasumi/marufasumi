## 📌 Project Highlights

### 💊 PharmacologyGPT

- Built a hybrid RAG pipeline using dense retrieval, BM25, and Reciprocal Rank Fusion
- Added query routing, query rewriting, context fusion, and Tavily web search
- Processed approximately **3,081 pages** and **17,879 vector chunks**
- Deployed an interactive Streamlit application

### 💊 FAERS Drug Safety Analytics

- Integrated and analyzed **406,184 FDA adverse-event reports**
- Built a **51-feature** report-level modeling dataset
- Evaluated **9 machine learning models**
- Best model: **Random Forest**
  - Accuracy: **92.58%**
  - ROC-AUC: **96.85%**
  - F1-score: **93.25%**
  - Cross-validation accuracy: **92.44%**
